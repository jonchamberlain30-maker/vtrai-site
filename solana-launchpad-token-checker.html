Launchpad token FAQ

Is a launchpad token safer than a random contract?

Not automatically. A launchpad may standardize creation and discovery, but it does not replace mint, authority, route, liquidity, and proof checks.

What should I paste into Vectora?

Paste the token mint or contract address. If you only have a pair page, use the token address, not the pair address.

Should every launchpad token get a public receipt?

No. Most should be ignored quickly. Create a public receipt when the token is worth revisiting or the community is arguing over proof.

Does this promise the token is safe?

No. Vectora publishes first-pass verification context, not guarantees. The aim is to slow down bad decisions and make proof easier to compare.
